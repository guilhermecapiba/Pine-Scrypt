## O que cada status significa

| Status | Significado | O que fazer depois |
|---|---|---|
| `PROMISSORA_PINE_GERADO` | Passou na régua; Pine pronto em `pine/` | Rodar no TradingView |
| `REFINADA_PROMISSORA_PINE_GERADO` | Passou só depois de refino de 1 parâmetro; Pine pronto | Rodar no TradingView |
| `PROMISSORA_VARIANTE_COBERTA_PELO_PINE_EMA10_SMA90` | Mesma regra do `EMA10_SMA90_ATR_BTC_1D.pine` com alvo 2,0R | Nada (use o input `alvoRR`) |
| `EM_PRODUCAO` | Já roda na Machine 2 | Nada |
| `REPROVADA_REGUA_PADRONIZADA` | Reprovou no backtest padronizado | Nada |
| `DUPLICATA_DE_...` | Mesma regra de outra linha | Nada |
| `DESCARTADA_REGRA_NAO_FORMALIZADA` | Rótulo sem regra testável | Nada |
